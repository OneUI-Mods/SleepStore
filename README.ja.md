# SleepStore

日本語 · [English](README.md)

Samsung One UI のディープスリープを維持したまま、Play ストアと Galaxy Store からアプリの更新を確認するための Xposed モジュールです。

## 仕組みと対象

ストア内で取得するアプリ情報だけを変更します。OS の状態が `DISABLED_UNTIL_USED`（4）で、さらに Samsung の `isPackageAutoDisabled` が真のアプリに限り、有効として見せます。通常の無効化（2／3）、Samsung の確認が取れないアプリ、判定失敗時は元の値を維持します。

ディープスリープの一覧、MARs の制限、実際の有効・無効設定は書き換えません。アプリを順番に起動する操作も行いません。Android システムやデバイスケアをフック対象に含めないでください。

ストアのサーバー側の配信条件や対応バージョンは変わりません。更新の検出と実際のインストールは区別して検証してください。インストール処理自体で Samsung が状態を変更する可能性は別途確認が必要です。

## 導入

1. Samsung Android 16 と稼働中の Vector / LSPosed 互換環境を用意します。検証環境は Vector 2.2（3080）です。
2. APK をインストールし、フレームワークで SleepStore を有効にします。
3. 対象に Play ストアと Galaxy Store を選びます。本アプリも選択すると、UI 内でフレームワークとの接続を表示できます。
4. 両ストアを強制終了して開き直し、更新を確認します。Runner の操作は不要です。

初期導入は個人プロファイル（user 0）のみです。他のプロファイルは別途対象設定が必要です。

UI は Material 3、ライト／ダーク、自動配色、日本語／英語／端末言語への追従に対応し、ライセンス全文を収録しています。接続表示は本アプリだけの状態であり、ストアへのフックを証明する表示ではありません。

## 開発と管理

JDK 21、Android SDK 36 を使用し、`./gradlew assembleDebug testDebugUnitTest lintDebug` でビルド・単体テスト・Lint を実行します。GitHub Actions でも同じチェックと APK の保存を行います。

デバッグ署名はビルドする環境ごとに異なります。配布版の継続更新には固定したリリース署名の設定が必要です。Samsung Android 16 / One UI 8.5 と Vector 2.2 で、両ストアから216件の自動無効化アプリを参照でき、通常の無効化とOSのディープスリープ制限が維持されることを確認しました。ストアの更新一覧への反映は検証中です。詳細な端末情報と内部メモは公開リポジトリに含めません。

## 元に戻す

Vector / LSPosed で本モジュールを無効にするか、アンインストールし、両ストアを再起動してください。ディープスリープ設定の復元作業は不要です。
